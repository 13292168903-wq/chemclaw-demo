# Diels-Alder 反应过渡态的 DFT 研究

## 1. 计算方法
全部计算使用 Gaussian 16，采用 B3LYP-D3BJ/def2-SVP 级别，过渡态搜索使用
opt=(ts,calcfc,noeigentest) 并做频率分析确认驻点性质。能量为电子能加 ZPE 校正后的值。

## 2. 结果
优化收敛后得到 TS-1，仅有一个虚频 -431.6 cm⁻¹，对应两个端位碳之间的成键振动，
满足一阶鞍点的判据。为确认该虚频确实连接反应物与产物，补做了 IRC 计算，
两端分别收敛到反应物复合物与产物。

反应能垒（ZPE 校正）为 18.6 kcal/mol，处于室温可讨论区间，说明该反应在加热条件下可发生。
前线轨道方面，HOMO 为 -6.80 eV，LUMO 为 0.54 eV，HOMO-LUMO gap 为 7.35 eV，
gap 偏大，提示需要较强的电子给体或受体取代基才能有效降低能垒。

## 3. 对照与讨论
为验证取代基效应，设计了 -OCH3 与 -NO2 两个取代基的对照计算，其余设置完全一致，
结果显示给电子基使能垒下降约 2.1 kcal/mol，与 Hammer 关系趋势一致。

## 4. 结论
TS-1 满足一阶鞍点判据，能垒 18.6 kcal/mol，反应在加热条件下可行。
